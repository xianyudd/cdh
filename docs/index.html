frequency × recency

cdh

Jump to the directory you mean, not the one you type. cdh scores your shell history with a frecency model — visit frequency times recency decay — then opens a terminal UI picker so the right path is one fuzzy search away.

$ curl -fsSL https://xianyudd.github.io/cdh/install.sh | bash

Works with bash, fish and zsh — the installer auto-detects your shell.

v0.3.2·Rust·MIT·MSRV 1.88

$ A picker that looks like your terminal, because it is one

One keybinding opens the picker inside your shell. Fuzzy-filter the candidates, read the preview, hit Enter — cdh performs the jump, hands the terminal back, and gets out of the way.

  • Candidates ranked by frecency — most-used paths float to the top
  • Type to fuzzy-filter across history and discovered directories
  • Move the selection — the preview follows with git status and last visit
  • Tab toggles the preview off for a full-width list, Tab again brings it back
  • F1 opens help; F2 opens settings: theme, language, preview, mouse
  • Esc clears the query — Enter jumps

The loop plays on its own and carries no audio. If your system prefers reduced motion you get the still frame instead.

# What you get

A small binary with a few opinions, all of them about getting you to the right directory faster.

📉

Frecency scoring that decays

Visit frequency is blended with a recency half-life and fused across multiple signals — so a directory you lived in last month stops crowding out the one you opened five minutes ago, and $HOME no longer bosses the leaderboard.

🔍

Fuzzy search with live preview

Type a fragment, get instant re-filtering. The preview pane shows directory contents, the git branch and dirty state, and when you last visited — before you commit to the jump.

🌳

History plus directory tree

The candidate pool merges your cd history with a background scan of the tree, so directories you have never visited are still findable. Ctrl+D excludes a subtree for good.

🎨

Seven themes

Graphite, Nord, Daylight, Mono, Dracula, Amber and Forest — with full no-colour fallback, because a picker should respect your terminal, not fight it.

🌏

Bilingual interface

The whole TUI speaks English and 中文, switchable in settings. Fullwidth input like ？ works in the query line too.

🖱️

Mouse support, honest keys

Click to select, double-click to jump, wheel to scroll — and a complete keyboard map (F1 help, F2 settings, F4 exclusion list) for when you never leave the home row.

🧊

A quiet corner cube

A small ambient 3D cube animates in the corner — non-blocking, off in no-colour mode, disableable via environment variable, and never in front of your selected row. Terminal bling with manners.

🦀

One Rust binary, XDG-clean

Single static-friendly binary from Rust with MSRV 1.88. History and state live under ~/.local/share/cdh and ~/.local/state/cdh; shell integration is a lightweight hook for bash, fish and zsh.

λ Three ways in

Pick whichever fits your machine. The curl installer auto-detects your shell and wires up the hook.

01Curl installer

One line, any of the three shells.

# auto-detect shell
curl -fsSL https://xianyudd.github.io/cdh/install.sh | bash

# or pin a shell explicitly
curl -fsSL https://xianyudd.github.io/cdh/install.sh \
  | bash -s -- --shell zsh

Shell hooks: bash fish zsh

02cargo install

If you already live in Cargo.

cargo install cdh

Then add the shell hook with the curl installer, or follow the README.

03GitHub Releases

Prebuilt binaries, no toolchain needed.

# example: Linux x86_64
curl -fsSL https://github.com/xianyudd/cdh/releases/download/\
v0.3.2/cdh-v0.3.2-x86_64-unknown-linux-gnu.tar.gz \
  | tar -xz

Targets: Linux gnu/musl (x86_64, aarch64) · macOS — see Releases.
