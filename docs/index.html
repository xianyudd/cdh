01 / the picker

It looks like your terminal because it is one

One keybinding opens the picker inside your shell. Fuzzy-filter the candidates, read the preview, hit Enter — cdh performs the jump, hands the terminal back, and gets out of the way.

  1. 01Candidates arrive ranked by frecency, so the paths you actually live in float to the top
  2. 02Type to fuzzy-filter across your history and the directories cdh discovered
  3. 03Move the selection and the preview follows, with git status and last visit
  4. 04Tab drops the preview for a full-width list, Tab again brings it back
  5. 05F1 opens help, F2 opens settings: theme, language, preview, mouse
  6. 06Esc clears the query, Enter jumps and gives the shell back

The loop plays on its own and carries no audio. If your system prefers reduced motion you get the still frame instead.

02 / what you get

The parts that do the work

One binary, one scoring model, one picker. Here is what each of them gives you.

f×r

Frecency scoring that decays

Visit frequency is blended with a recency half-life, so the directory you lived in last month stops crowding out the one you opened five minutes ago. $HOME no longer owns the top of the list.

Tab

Fuzzy search, live preview

Type a fragment and the list re-filters as you go. The preview pane shows contents, git branch and dirty state, and when you were last there — before you commit to the jump.

Ctrl+D

History plus the whole tree

The candidate pool merges your cd history with a background scan of the tree, so paths you have never visited are still findable. Ctrl+D excludes a subtree for good.

F2

Seven themes

Graphite, Nord, Daylight, Mono, Dracula, Amber and Forest, switched in settings (F2) or cycled with Ctrl+T or F3. No-colour terminals get a full fallback.

文A

English and 中文

The whole TUI speaks both, switchable in settings. Fullwidth input like ？ works in the query line too.

F1

Mouse, and honest keys

Click to select, double-click to jump, wheel to scroll. The keyboard map is complete: F1 help, F4 exclusions, Ctrl+H or F5 for hidden directories.

◇

A quiet corner cube

A small ambient cube animates in the corner: non-blocking, off in no-colour mode, disabled by an environment variable if you want it gone. It never covers the selected row.

~/

One Rust binary, XDG-clean

A single static-friendly binary built at MSRV 1.88. History and state live under ~/.local/share/cdh and ~/.local/state/cdh; the shell hook is a few lines for bash, fish or zsh.

03 / install

Three ways in

Pick whichever fits your machine. The curl installer auto-detects your shell and wires up the hook.

01

Curl installer

One line, any of the three shells.

# auto-detect shell
curl -fsSL https://xianyudd.github.io/cdh/install.sh | bash

# or pin a shell explicitly
curl -fsSL https://xianyudd.github.io/cdh/install.sh \
  | bash -s -- --shell zsh

Shell hooks: bash fish zsh

02

cargo install

If you already live in Cargo.

cargo install cdh

Then add the shell hook with the curl installer, or follow the README.

03

GitHub Releases

Prebuilt binaries, no toolchain needed.

# example: Linux x86_64
curl -fsSL https://github.com/xianyudd/cdh/releases/download/\
v0.3.2/cdh-v0.3.2-x86_64-unknown-linux-gnu.tar.gz \
  | tar -xz

Targets: Linux gnu/musl (x86_64, aarch64) · macOS — see Releases.
